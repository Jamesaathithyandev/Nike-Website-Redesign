# Nike-Website-Redesign

A high-end, editorial Nike Informational & Heritage Archive showcase built with **Next.js 14**, **Tailwind CSS**, and **GSAP**.

## Features

- **Hero Presentation**: Hand presenting the dual Air Jordan 1 Retro sneakers with smooth synchronized entrance animations and right-aligned editorial typography.
- **Metrics Showcase**: Modeled directly after the reference design, featuring global athlete reach, innovation lab statistics, and glowing orange underline progress indicators.
- **40-Year Heritage & Circular Cluster**: Interactive honeycomb cluster with 6 floating innovation badges (Swoosh, Jordan Wings, Air-Sole, Flyknit, React Foam, ISPA) featuring hover glow and detailed technological breakdown cards.
- **Sneaker Catalog (`/shop`)**: Curated archival showcase displaying 6 iconic Nike silhouettes (Jordan 1 Retro, Jordan 1 Chicago, Dunk Low Panda, Air Max 90, Air Force 1, Jordan 4 Bred) with category filtering, search, and full-screen inspection modal.
- **Universal About & Contact**: Complete Beaverton World Headquarters information, Bowerman heritage narrative, direct inquiry dispatch form, and newsletter subscription on all pages.
- **Volumetric Studio Backdrop**: Multi-layered ambient lighting, dynamic mouse-tracking spotlight, subtle geometric architectural grid, and photographic film grain.
- **Scroll-Triggered Animations**: Hardware-accelerated entrance reveals on all sections as the user scrolls down.

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   npm start
   ```

Open [http://localhost:3000](http://localhost:3000) to view the website.
